# VideoAutoTranslate 产品需求文档

状态：设计基线，尚未实现。本文定义产品行为；[架构设计](architecture.md)定义实现约束，[UI 与交互设计](ui-design.md)定义界面及操作细节。

## 1. 产品定位与范围

面向 macOS Apple Silicon 的本地视频字幕制作与多语言配音工作站。核心价值是让自动生成的字幕能够被可靠地校对、拆分、合并和调整时间，再用于翻译和配音。

- 输入用户已有的本地媒体，不集成 `yt-dlp` 或网络视频下载功能。
- Swift / SwiftUI 原生应用，交付物不要求用户安装 Python。
- ASR 与对齐优先本地运行，候选为 Qwen3-ASR 与 Qwen3-ForcedAligner；翻译默认探测本地 Ollama / Qwen，允许用户主动配置云端服务。
- 首次使用需要下载模型或导入模型；仅在所需模型、音色均已就绪且选择本地引擎时，才能完成离线流程。失败时不能自动切换到云端或发送内容。
- 字幕编辑是第一阶段核心。自动生成是起点，用户始终能人工修正时间和文本。

### 1.1 交付阶段

| 阶段 | 必须形成的闭环 | 暂不作为该阶段交付条件 |
| --- | --- | --- |
| M0 技术验证 | 原生包内 ASR / 对齐可运行；媒体读取、长音频分块和模型内存测量 | 完整工作台 |
| M1 字幕编辑 | 导入 → 转录 → 校对 → 拆分/合并/调时 → 保存/恢复 → SRT/VTT 导出 | 配音、软/硬字幕视频、批量任务 |
| M2 翻译与成片 | 上下文翻译、术语表、双语校对、字幕样式和视频导出 | 自动配音 |
| M3 配音 | 单句生成/试听、人声分离、时长冲突处理、混音与视频导出 | 多人声音克隆、口型同步 |

M1 必须具备双语数据结构和译文编辑能力，翻译未配置时仍能独立完成转录、编辑及原文字幕导出。多人重叠语音先保留并标记待处理，不承诺自动说话人分离。

## 2. 用户工作流

1. 新建或打开项目，拖入本地媒体，检查时长、音轨及可解码能力。
2. 选择源语言（可自动检测）、识别模型与识别场景，运行转录。
3. 查看视频、双语列表和波形；校对原文，处理边界和断句问题。
4. 按需选择目标语言、术语和翻译引擎；翻译后允许逐句修改、重译及锁定人工译文。
5. 校验问题，选择原文、译文或双语输出；预览后导出。
6. 后续阶段允许按稳定的字幕版本生成配音、解决超时并导出混音视频。

允许在任何已完成阶段保存并退出。模型下载、转录、翻译失败不能使已编辑内容丢失。

## 3. 媒体、模型与识别

### 3.1 导入

- M1 优先验证 MP4/MOV 中的 H.264/HEVC 与 AAC/PCM 组合，不按扩展名保证可播放。
- 其他容器（包括 MKV/WebM）属于待验证支持：导入时探测容器、编解码器、音轨及实际读取能力；无法处理时说明原因。是否引入额外解封装/转码组件由 M0 验证决定。
- 多音轨媒体提供音轨选择；无音轨时允许预览和手工编辑，禁用转录并解释原因。
- 分块读取音频，使用有界内存及可清理的磁盘缓存；不要求整部媒体常驻内存。
- 保留源文件，项目引用文件发生移动时提供重新定位，禁止静默改用其他文件。

### 3.2 模型准备与运行

- 模型管理显示引擎、版本、大小、下载/校验/加载状态、磁盘用量和离线可用性，支持取消、重试和本地导入。
- 本地服务不可用时，允许启动服务、选择其他本地模型或主动配置云端；不阻塞字幕手工编辑。
- Qwen3-ASR 的识别语言范围与 ForcedAligner 的对齐语言范围分别显示；不支持词级对齐的语言保留句级时间和人工调时能力。
- 识别结果保留词级时间和文本范围。自动断句结合停顿、标点、阅读速度、字数与时长，禁止通过截断结束时间来满足最长显示时长。
- 字幕行宽默认参考中文约 20 字、英文约 40 字符，可配置；同时检查显示行数、阅读速度和画面安全区，不以字符数保证可读性。

## 4. 字幕编辑语义（M1 核心）

### 4.1 必须区分的操作

| 操作 | 文本 | 显示区间 | 字幕数量 |
| --- | --- | --- | --- |
| 行内换行 | 插入排版换行 | 不变 | 不变 |
| 拆分字幕 | 原文分为两条；译文独立确认 | 分为两个有效区间 | 增加一条 |
| 合并字幕 | 按项目顺序拼接 | 首句起点至末句终点 | 减少 |
| 调整边界 | 不变 | 修改起点或终点 | 不变 |
| 整句移动 | 不变 | 起止同时移动、时长不变 | 不变 |

词时间是实际发音锚点，字幕时间是显示区间，二者不得混为一个字段。停顿可以留空，不要求字幕覆盖整段媒体。

### 4.2 文本编辑与对齐有效性

- 原文和译文可行内编辑，输入法组词期间不得触发拆分或提交未完成文本。
- 修改原文后，保留未受影响的有效映射；受影响区间标记“待对齐”。标点和排版变化可以经映射验证后保留锚点，不能仅凭字符数量判断有效。
- 对齐不可用时仍可人工调时，但不能伪装成精确词级拆分。提供局部重新对齐及手动选择时间点。
- 人工修改的时间边界受保护；重新对齐先展示建议，由用户应用，不能后台覆盖。
- 原文变化使关联译文标记“待复核”，保留人工文本；译文变化使配音标记“待更新”。

### 4.3 拆分

- `Cmd+B`：原文编辑焦点下使用文本光标；时间轴焦点下使用播放头；其他焦点下禁用并提示可用位置。菜单另外提供明确的两种拆分入口。
- 文本拆分默认吸附到最近的有效词边界，预览实际文字断点与时间；不静默拆开英文单词或 Unicode 字素。距离相同时优先前边界。
- 停顿内有多个合理时间点时，默认取前词结束与后词开始的中点，并允许试听和修正。词时间重叠、缺失或过期时不能自动给出“精确”断点。
- 播放头拆分需要同时确认原文断点；无有效映射时由用户选择文字位置和时间。
- 原文无译文且边界唯一有效时直接执行；需要选择断点或分配译文时进入内联预览，确认前不修改项目。
- 已有译文时，默认展示原译文及两个译文输入区，由用户选择译文断点；系统建议只能作为草稿。可暂缓分配，原译文保存在待分配记录中，两条字幕显示“译文待分配”。不按原文字数比例强切或静默丢弃译文。
- 自动拆分要求两侧非空且各自不少于 100ms；100ms 是结构保护阈值，不是推荐阅读时长。过短字幕另外给出可读性警告。
- 拆分成功后选中右句，保留左句和右句的来源关系；撤销一次恢复原字幕、译文和关联状态。

### 4.4 合并

- 仅允许同轨道中连续的至少两条字幕，按项目顺序处理，与点击选择的先后顺序无关。
- 不连续、跨轨道选择禁用合并；跨说话人或长停顿显示预览警告，不自动吞并未选中的字幕。
- 默认长停顿警告阈值为 1 秒，可配置；保留内部词时间和停顿，不重新均分时间。
- 拼接遵循语言的空格及标点规则，允许预览修正；人工译文保留并标记待复核，未分配译文记录一并保留。
- 原配音失效，保留可撤销引用，不能直接拼接旧配音冒充重新生成。

### 4.5 时间调整与播放

- 支持波形边界拖动、整句拖动、相邻共享边界调整及精确时间输入；拖动期间只预览，松开后形成一次可撤销修改。
- 普通边界拖动不移动相邻字幕；共享边界模式仅对原本首尾相接的相邻字幕开放，同时改变两句交界。
- 默认禁止同轨道新增重叠，遇邻句边界停止并提示；不允许越过媒体范围或把起点拖过终点。已有重叠导入后保留并列入问题列表，修复操作可以逐步减少原有冲突。
- 吸附到词边界、停顿中点、邻句边界或视频帧；可临时关闭。无视频的媒体按音频时间编辑。
- 支持单句循环、前后各 300ms 上下文试听（可调整）、前后句导航和慢速播放。
- 播放高亮、编辑选中及文本光标相互独立；用户编辑或滚动后暂停列表自动跟随，提供“跟随播放”恢复入口。

### 4.6 撤销、保存与校验

- 支持文本编辑、拆分、合并、调时、应用自动修复的撤销/重做。后台生成不能污染用户的编辑撤销顺序。
- 自动保存以已提交操作为单位；显示保存中、已保存、失败及重试状态。工程恢复包含文本、时间、人工保护状态、待分配译文及媒体引用。
- 问题列表至少覆盖无效/零时长、重叠、过短、过长、阅读过快、待对齐、译文待分配、翻译失败和配音超时；点击定位，批量修复先预览。
- 原文导出不受翻译状态阻塞。译文/双语导出遇未分配译文或失败行必须要求解决或明确选择跳过；待复核译文经用户确认后可导出。无效时间阻止对应轨道导出；已有重叠先警告并要求明确保留或修复。

### 4.7 初始编辑预设

以下为首版原型的可配置初值，不代表行业标准或已验证最优值。项目保存所用预设，修改预设仅重新计算问题提示，不自动改变人工字幕。

| 项目 | 初值 | 处理方式 |
| --- | --- | --- |
| 新拆分最短结构时长 | 100ms | 不满足则拒绝拆分 |
| 建议最短可读时长 | 800ms | 低于时警告，允许人工保留 |
| 建议最长显示时长 | 6s | 自动生成优先继续分段；人工字幕只警告 |
| 建议阅读速度上限 | 中文 10 字/秒，英文 20 字符/秒 | 分语言估计并警告，后续走查调优 |
| 每行参考上限 | 中文 20 字，英文 40 字符 | 同时检查实际渲染宽度 |
| 默认显示行数 | 单语最多 2 行；双语每种语言 1 行 | 超出时提示调整排版或拆分，不裁去文字 |
| 试听上下文 / 长停顿警告 | 前后各 300ms / 1s | 用户可调整 |

阅读速度统计忽略排版换行及纯空白，按语言适配器统计可见字符；不能以一种计数规则评判全部语言。原文词级拆分不受译文阅读速度警告阻塞。

## 5. 翻译、配音与导出

### 5.1 翻译

- 探测 Ollama 后展示可用模型；已有用户选择优先，不因启动探测而自动替换。
- 提供多个服务配置、连通性测试和模型列表；云端传输前显示将发送的文本范围。API Key 存入 Keychain，日志不记录密钥。
- 翻译携带字幕 ID、上下文、术语表和目标语言，返回逐 ID 结果并校验，禁止按返回行号盲目覆盖。
- 译文长度作为可读性约束，优先保留含义；过长时建议重译或重新分段，不直接截字。
- 失败保留原文与已有译文，展示失败状态并支持单句重试；不把原文回填为成功译文。
- 上下文或术语变化时提示相关译文待复核；人工锁定译文不能被批量重译覆盖。

### 5.2 配音（M3）

- 本地 TTS 必须指定经验证的模型、语言和音色后，才能宣称离线配音可用；在线 TTS 为用户自选服务。
- 候选人声分离模型需要验证转换、资源占用和听感；展示可能的人声残留及环境音损失，保留原声/分离背景切换试听。
- 保调变速的初始允许范围为 0.6～1.8 倍，需听感验证；变速后重新测量真实时长。
- 超出窗口时提供缩短译文、用户确认借用邻近空白、调整时间或保留超时待处理，禁止自动截掉语音或覆盖下一句。
- 只重算受影响的生成阶段。缓存试听与新生成耗时分开显示，不承诺任意引擎均能在 0.5 秒内合成。
- 背景音闪避依据实际配音区间，提供深度及恢复时间设置、响度与削波检查。

### 5.3 导出

M1 支持 SRT/VTT 原文、译文、双语与顺序配置；换行不会变成额外字幕。M2 增加样式预览、硬字幕视频及经容器兼容性验证的软字幕输出。M3 增加配音混音视频。

导出使用固定项目快照，显示目标、范围、语言、格式及问题摘要；避免覆盖源视频，已有目标文件由用户选择替换或另存。取消或失败不能把半成品标记为完成。

## 6. 验收与待验证项

| 场景 | 验收结果 |
| --- | --- |
| `Hello world` 词内、词间空格、句首句尾拆分 | 词内给出边界选择；不产生零时长、文本丢失或词归属错位 |
| 中文标点、emoji、组合字符和输入法组词 | 不破坏字素或未提交输入，不靠字符长度累加映射 |
| 译文语序不同、人工译文后拆分/合并 | 原译文可追溯；待分配可保存恢复，不伪造逐词对应 |
| 修改原文后立即拆分 | 过期映射不可用于自动拆分；人工调时仍可用 |
| 反向多选、不连续选择、邻句间有停顿 | 连续选择按项目顺序合并；其他情况禁用或警告 |
| 拖动边界、拖动取消、撤销重做 | 有效区间不越界，取消不提交，一次撤销恢复完整操作 |
| 编辑/撤销/拆分后旧翻译或配音返回 | 不覆盖新状态，不复活已删除字幕 |
| 10 秒连续讲话没有明显停顿 | 通过词边界继续分段，末尾文字有对应显示区间 |
| 项目关闭重开、保存失败、媒体移动 | 编辑状态完整恢复；失败可见，引用可重新定位 |

性能目标（待实测）：模型加载不阻塞界面；在 10,000 条字幕项目中普通编辑反馈 P95 小于 100ms，拖动交互目标为 60fps，已缓存单句试听启动 P95 小于 500ms。报告设备、媒体长度、冷/热启动、峰值内存和样本数量；ASR/TTS 延迟与时间戳误差按设备/模型/语言分别报告，不混同存储分辨率与识别准确度。

M0 必须确定最低 macOS、8GB/16GB 内存适配范围、Swift 推理依赖版本、模型许可证与分发方式、容器/编码支持矩阵。未通过验证的能力在界面和 README 中不得标成已完成。
