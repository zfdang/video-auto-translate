# VideoAutoTranslate UI 与编辑交互设计

状态：待实现设计规格。目标平台为 macOS Apple Silicon，使用 SwiftUI，必要时通过 AppKit 承接文本焦点、输入法和撤销。产品规则见 [PRD](PRD.md)，数据和事务见 [架构设计](architecture.md)。

## 1. 设计目标与信息层级

主任务是“听一句、改一句、调准边界、检查结果”。优先展示当前视频、正在编辑的字幕及对应波形；模型、服务和高级处理放在需要时打开的面板中。

一级页面为项目列表与项目工作台。工作台内以“编辑 / 问题”切换右侧内容，以检查器显示当前选择的属性。模型管理与应用设置独立打开，不占据字幕编辑区域；摘要、聊天和思维导图不进入 M1 主界面。

界面文案使用“原文、译文、待对齐、重新对齐、待分配、试听、调整时间”；不向普通用户暴露 token、revision、缓存键或模型内部字段。

## 2. 主工作台布局

建议初始窗口 1440×900pt，可缩放；最低目标 1024×700pt。以下是结构线框，不表示最终视觉稿。

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ 项目名 · 已保存       撤销/重做       转录   翻译       检查问题(3)   导出 │
├───────────────────────────────┬──────────────────────────────────────────┤
│                               │ 编辑 / 问题                搜索  筛选   │
│           视频预览            ├──────────────────────────────────────────┤
│      字幕按导出样式叠加        │ 12  00:12.300 → 00:14.800       待复核  │
│                               │ 原文：Welcome to Paris.                  │
│                               │ 译文：欢迎来到巴黎。                     │
│                               ├──────────────────────────────────────────┤
│ 播放/暂停  当前/总时长  速度   │ 13  当前选择                               │
│ 上一句  本句循环  下一句      │ 原文：[文本光标与词边界提示]               │
│                               │ 译文：[独立编辑，不与原文字数绑定]         │
│                               │ 试听  拆分  更多                          │
├───────────────────────────────┴──────────────────────────────────────────┤
│ 时间轴   跟随播放:关   吸附:开    缩小 ───── 放大     适合所选 / 全片   │
│ 标尺      00:12          00:13           00:14           00:15           │
│ 波形     ▂▅▇▅▂  ▃▆▆▃                  ▂▆▅▃                            │
│ 原文轨   [ 12                         ][ 13                          ]   │
│                        ↑播放头       ↔边界                              │
│ 状态：字幕 13 / 86     对齐有效       [开始] [结束] [持续时间]            │
└──────────────────────────────────────────────────────────────────────────┘
```

- 预览/字幕列表间可拖动分隔，时间轴高度可调；布局偏好按用户保存。
- 1440pt 宽时预览约占上区 45%，字幕约占 55%；打开属性检查器时从字幕侧分配空间，不遮挡播放控制。
- 小于 1200pt 时默认关闭项目侧栏和检查器，上区比例可调整；小于建议尺寸时允许切换“视频/字幕”而不挤压文本，时间轴保留。
- M1 显示一条可编辑字幕轨和源音频波形；原文/译文共享同一字幕显示区间。M3 再增加配音、背景轨，按需展开，不提前铺满空轨道。

## 3. 字幕列表与文本编辑

### 3.1 行结构

每行显示序号、起止时间、原文、译文及状态；译文为空时显示“添加译文”，无目标语言时可收起译文。状态包括待对齐、待复核、待分配和失败，使用图标、文字及颜色共同表达。

- 单击行的时间或空白区域选中字幕并定位播放头；单击文本进入编辑，不强制跳转或打断播放。
- 正在播放的行有细播放标记，选中行有背景高亮，文本光标仍是独立状态；允许三者位于不同位置。
- 行内按钮只显示高频的试听、拆分与更多；合并在多选时出现在上下文工具栏中。
- 搜索覆盖原文和译文，查找/替换需明确语言与范围；批量替换先给出数量和预览，作为一次可撤销事务。不能修改锁定译文而不提示。
- Shift 选择连续行，Cmd 切换单行选择；多选中的不连续状态仍可删除或批量标记，但合并禁用并说明原因。

### 3.2 编辑提交与自动保存

输入过程中即时更新预览；本地编辑缓冲以 500ms 空闲或焦点离开形成提交，撤销按合理打字组组织。输入法正在组词时不提交、不拆分；切换项目/关闭窗口时先完成已提交文本保存，并按系统输入法规则处理组合文本。

Return 在多行文本中插入排版换行，Tab 移至同句另一语言，Shift+Tab 返回；Esc 结束编辑并保留已提交文本。拆分面板内 Esc 取消提案，不修改正文。

右侧检查器显示精确起止时间、持续时间、对齐状态、人工边界保护、译文锁定与问题解释；时间输入接受 `HH:MM:SS.mmm`，错误在字段旁显示且不提交无效值。日常编辑不要求打开检查器。

## 4. 拆分字幕

### 4.1 入口与焦点

- 原文中 `Cmd+B`：按文本光标拆分。
- 时间轴中 `Cmd+B`：按播放头拆分。
- 译文中不把译文字符位置当作音频锚点；提供“拆分字幕…”按钮进入双语提案，要求选择原文/时间断点。
- 工具栏与菜单分别标明“按原文光标拆分”“按播放头拆分…”，不可用时给出原因，例如“请先选中一句字幕”。
- 输入法组词、搜索框、时间输入框或其他文本字段中不截获 `Cmd+B` 作为项目拆分。

### 4.2 内联预览

无译文且断点唯一有效时直接执行；存在词内光标、无有效对齐或已有译文时，在当前行下展开预览，原列表和波形继续可见。

```text
拆分字幕 13                         [试听断点] [取消] [确认拆分]
原文：Welcome to | Paris.
      实际断点吸附到词边界；可选择前一个/后一个边界
时间：[00:13.420]     左句 1.12s / 右句 1.38s
译文：欢迎 | 来到巴黎。             [暂不分配译文]
提示：译文断点需按含义确认，不必与原文字符比例一致。
```

- 同时在波形上画出断点和左右覆盖区间；拖动断点更新左右时长及约束提示。
- 原文词内点击时显示吸附前后差异，允许用户选另一词边界；不静默切开字素。
- 无对齐显示“当前原文已修改，请重新对齐或手动选择时间”，提供局部重新对齐和人工断点输入。
- 译文断点通过独立光标选择；建议分配显示“建议，待确认”。选择暂缓时保留原译文，后续可从“待分配”面板补分，保存重开后仍可见。
- 确认按钮仅在原文两侧非空、时间有效且满足最短结构时长时启用；短于可读性建议但结构有效时给警告。
- 完成后选中右句并把光标放到开头，轻提示“已拆分 · 撤销”。

## 5. 合并与时间轴操作

### 5.1 合并

选择两条或更多同轨连续字幕后，工具栏显示“合并 N 条”，快捷键 `Cmd+J`。短停顿且无语义风险时直接合并；跨说话人、长停顿或存在待分配译文时预览文本、区间和警告。无效选择显示禁用原因，不通过隐式补选实现连续。

合并保持首尾和内部词时间；文本拼接可在预览修改。成功后选中新句，原始句子及资源引用可一次撤销恢复。

### 5.2 拖动与精调

| 手势/控件 | 作用 | 反馈 |
| --- | --- | --- |
| 拖动字幕块左/右把手 | 单独改起点/终点 | 新时间、增减量、吸附线、冲突原因 |
| 拖动字幕块主体 | 整句平移 | 起止同量变化，文字保持 |
| 在相接边界选择“共同调整”后拖动 | 同时改变前句终点与后句起点 | 两句时长同时显示 |
| 单击标尺/波形 | 定位播放头 | 预览跳转，选中状态不强制改变 |
| 缩放滑杆/适合所选 | 放大编辑范围 | 缩放围绕播放头或当前选择，不丢失定位 |
| Option 拖动 | 临时关闭吸附 | 吸附状态临时标识 |
| Escape | 取消当前拖动 | 恢复拖动前状态 |

吸附默认 6px，候选优先级及约束见架构文档。拖到邻句、媒体边缘或最小时长时停止并显示说明，不能偷偷推移后续字幕。键盘精调起点/终点使用检查器按钮或菜单命令，步长可选 10ms、100ms、视频帧；无视频时不显示帧步长。

时间轴上保留静音间隙。导入的重叠用冲突带和问题项表示，不自动裁短。视图只渲染可见范围，拖动中不触发重新转录、翻译或保存风暴。

### 5.3 播放跟随与试听

Space 在播放器或时间轴焦点下播放/暂停；文本编辑中正常输入空格，`Cmd+Return` 可试听所选句。循环入口明确显示“本句循环”，可包括前后各 300ms 上下文。

播放只更新播放标记，不改变编辑选中。手动滚动或进入编辑时关闭列表自动跟随；顶部提供“跟随播放”按钮恢复。字幕预览默认使用已提交或当前编辑缓冲的显示文本，导出预览则使用锁定快照并标明范围。

## 6. 问题面板、任务与状态

### 6.1 问题面板

问题按阻塞导出、时间问题、文本可读性、对齐/翻译/配音状态过滤。每项显示原因、定位和修复入口，例：“字幕 13 与 14 重叠 180ms”。

自动修复先展示修改前后区间/文本与影响数量；允许逐项选择和取消，一次应用可撤销。不采用只提供“全部修复”且不可预览的入口。译文待分配项直接打开保存的原译文与两个子句。

### 6.2 任务与错误

- 转录/翻译显示具体阶段、已处理时长或句数、可取消与失败重试；没有可靠总量时不用伪精确百分比。
- 模型未准备：显示大小、下载/导入入口与离线说明；可先打开工程手工编辑。
- 无音轨/格式不支持：显示检测原因及可执行下一步，避免直到转录末尾才报告。
- 服务不可达：区分未启动、认证失败、超时与限流；保留编辑内容，不自动向云端重试。
- 对齐失败：保留字幕时间，提供重试或人工调时；不要清空原文。
- 保存失败：持续显示“未保存”及重试/另存；关闭前明确告知未写入内容。
- 长任务进行时仍允许编辑无依赖内容。编辑使结果过期时显示“内容已更新，需重试”，不闪回旧结果。

### 6.3 空状态与首次使用

项目页提供打开/新建及最近工程；空项目可拖入媒体或使用文件选择器。首次流程只询问当前必须项：媒体、音轨、语言、识别引擎。识别配置允许“仅转录”，不要求先填写翻译密钥。

模型准备面板分别显示已下载、校验中、加载中及不可用，不把“下载完成”当作“可运行”。模型与服务配置测试只有在用户点击测试后发送测试文本，并标明目标服务。

## 7. 导出与配音扩展

导出面板按“内容 → 格式 → 位置”组织：原文/译文/双语及顺序、SRT/VTT（M1）、后续视频选项、输出路径。显示实际预览及问题摘要；遇阻塞错误提供返回对应问题的入口。文件已存在时明确选择替换或另存，不能默认覆盖源媒体。

M3 在所选句显示配音状态、生成、试听、音色与真实时长。配音超出窗口时呈现“需要 2.2s / 可用 1.0s”，并提供改译文、借用空白、调时三个具体入口；不只显示模糊的“对齐失败”。原声、背景和新配音可分别试听，试听期间不修改导出配置。

## 8. 视觉、无障碍与快捷键

- 使用系统字体、系统强调色、浅色/深色外观；数字时间采用等宽数字。原文与译文通过标签和字号层级区分，避免只用颜色区分。
- 波形和字幕块保持足够对比度；选中、播放、错误、焦点四种状态不能共用一种高亮。
- 所有图标按钮提供提示、菜单入口和 VoiceOver 标签；边界把手可通过键盘及时间字段替代，支持减弱动态效果。
- 自动滚动和状态提示不频繁抢占 VoiceOver 焦点。错误用文字解释，不只弹瞬时通知。
- 快捷键在 macOS 菜单中可发现；焦点路由需专门验证 AppKit 文本编辑、输入法和 UndoManager。

| 快捷键 | 编辑器行为 | 焦点限制 |
| --- | --- | --- |
| Cmd+B | 文本光标/播放头拆分 | 仅原文或时间轴；其他位置不劫持 |
| Cmd+J | 合并连续字幕 | 字幕选择上下文 |
| Cmd+Z / Cmd+Shift+Z | 撤销/重做 | 编辑器事务；输入法和原生文本优先正确路由 |
| Return | 字幕内排版换行 | 多行文本编辑 |
| Space | 播放/暂停 | 仅播放器/时间轴，编辑文本时输入空格 |
| Cmd+Return | 试听当前句 | 工作台所选句，输入法组合期间禁用 |
| Cmd+F | 查找字幕 | 工作台 |
| Cmd+S | 立即保存 | 项目上下文 |
| Escape | 取消提案/拖动，或退出编辑 | 优先最内层临时状态 |

## 10. UI 验收清单

实现前需以交互原型验证以下连续任务，再进入原生组件开发：

1. 导入短视频，识别后从任意行定位、循环试听，修改原文且不被自动滚动打断。
2. 在英文词内、词间空格、中文标点、emoji 附近拆分，能理解实际断点和时间。
3. 拆分语序不同的双语字幕，暂缓译文分配，保存重开后完成分配。
4. 拖动单边界、整句移动、共享边界调整，关闭吸附、取消及撤销，确认不会意外移动邻句。
5. 播放中编辑、后台翻译中拆分/撤销，界面不抢焦点、不覆盖人工修改。
6. 从问题面板定位重叠，预览修复，再导出；仅转录时不被翻译配置阻塞。
7. 在最小窗口、深色模式、键盘和 VoiceOver 下完成同一组核心操作。

交互原型和真实用户走查尚未完成；本文件是后续原型与实现的验收依据，不表示界面已经实现。
