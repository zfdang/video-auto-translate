**在 Mac 上完成视频识别、双语字幕校对与多语言配音。**

VideoAutoTranslate 是面向 macOS 14 及以上、Apple Silicon 的原生视频翻译工作站。从本地视频出发，将语音识别、翻译、时间轴编辑、配音和成片导出放在同一个工作台中。

[下载应用](https://github.com/zfdang/video-auto-translate/releases/latest) · [项目网站](https://vat.zfdang.com) · [安装与设置](docs/getting-started.md) · [反馈问题](https://github.com/zfdang/video-auto-translate/issues)

## 核心功能

- **本地语音识别**：使用 Qwen3-ASR 与 Qwen3-ForcedAligner 识别语音、对齐逐词时间戳，并生成可编辑字幕。模型支持共享缓存、应用独立目录与自定义存储位置。
- **多语言字幕翻译**：默认连接本地 Ollama，可选用提供 OpenAI 兼容接口的在线服务。原文与译文并排校对，重新翻译可继续处理未完成或待复核的行。
- **细致的字幕编辑**：逐句修改文本和时间，搜索原文或译文，按词拆分（`⌘B`）、合并相邻字幕（`⌘J`）。修改原文后会标记译文待复核，避免将过期译文带入成品。
- **配音与时间轴匹配**：支持 Edge TTS 和系统原生音色，可逐句试听、局部重新配音。根据所选音色的实测时长，让同语境的相邻句子共享时间，并在需要时适配语速。
- **灵活导出**：导出双语、仅译文或仅原文的 SRT / WebVTT 字幕；也可导出 MP4，组合字幕与纯译文配音、原声压低叠加或原始音轨。
- **保存工程，继续制作**：保存 `.vatproject` 工程，保留字幕、配置与配音状态，方便下次继续校对和导出。

## 工作流程

### 1. 导入视频

打开本地视频，在播放器中预览画面与原声。应用专注本地媒体处理，不包含网络视频下载功能；可读取的媒体格式取决于系统解码支持。

### 2. 识别语音

选择源语言或自动检测，运行语音转录。识别与词级对齐在本机完成，生成带时间戳的原文字幕。先校正识别错误，再进入翻译。

### 3. 翻译与校对

选择目标语言并翻译字幕。可随时修改原文和译文、拆分或合并句子。修改原文后，编辑对应译文即可确认；译文无需改字时，点击该行「确认译文」。导出前需处理相关待复核项。

### 4. 匹配译文时间轴

需要配音时，选好引擎和音色，点击「匹配译文时间轴」。应用实测配音时长，在局部语境内重新分配各句时间，保持每组的开头和结尾与视频一致。预览时间变化、试听后确认应用；短句自然留白，语速偏快会显示提示。

匹配结果会被后续生成、试听和导出复用。原始时间戳始终保留，重复匹配不会积累全片漂移。算法细节见[时间轴设计说明](docs/translation-timeline-algorithm.md)。

### 5. 试听与配音（可选）

逐句试听译文，或生成整片配音。单句试听也支持直接播放正常语速音频；修改译文后可仅重新生成该句。若配音超出当前时间区间，先重新匹配时间轴。

只需要字幕时，可以跳过时间轴匹配与配音，直接导出。

### 6. 导出字幕或成片

按用途选择独立字幕或 MP4 成片，并选择字幕语言与音轨。原声压低叠加会保留原人声，目前不提供人声分离。保存工程后，下次可继续编辑。

## 本地与在线服务

| 环节 | 本地方案 | 在线方案 |
| --- | --- | --- |
| 语音识别与对齐 | Qwen3-ASR + Qwen3-ForcedAligner | — |
| 字幕翻译 | Ollama（默认模型 `qwen2.5:latest`） | OpenAI 兼容接口 |
| 语音合成 | macOS 系统音色 | Edge TTS（默认，无需 API Key） |
| 媒体处理与导出 | macOS 原生多媒体框架 | — |

模型与所需系统音色准备完成后，选择本地 Ollama 和系统 TTS 可离线完成流程。首次下载模型、在线翻译和 Edge TTS 需要联网；选择在线服务时，相关字幕文本会发送给该服务。
