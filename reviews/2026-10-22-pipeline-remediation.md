# 音视频管线审查核实与修复（2026-10-22）

基于当前主分支逐项核实，报告中的 8 项均有对应代码问题或缺失能力。

| 项目 | 核实结果 | 修复与边界 |
| --- | --- | --- |
| 1. TTS 未启动 Sidecar | HTTP 请求前没有唤醒服务，失败后逐句走 CLI | 默认本地端点请求前调用 ensureRunning；自定义端点继续直接请求；保留故障回退和取消检查 |
| 2. 容器时长漂移 | 原始结束时间严格要求不超过视频时长 | 接受最多 0.5 秒漂移并截断有效结束点；保持原始 ASR 锚点；仍拒绝截断后不足 100ms、完全落在视频外或明显越界的行 |
| 3. 硬字幕动画越界 | 结束关键帧可能大于 1，并使数组逆序 | 截断可见区间，跳过无效或不可见字幕，关键帧全部限制在 [0, 1] 且非递减 |
| 4. ASR 全量缓冲 | WAV 全量加载后复制到 multipart Data | 64KiB 分块写入临时 multipart 文件，再从文件上传；成功、失败、取消均清理临时文件 |
| 5. 抽取缺少取消 | 原流程未连接任务取消与 reader/writer | 在串行队列管理读写、完成回调和 continuation；取消标志受锁保护，每次写入前检查；取消能唤醒停滞的 writer；清理临时文件并保留已有输出 |
| 6. Sendability 捕获 | 基线编译复现四类抽取对象和两处 export session 捕获告警 | 抽取回调仅捕获受串行队列保护的操作对象；导出取消仅捕获限定用途的取消桥接对象；没有为 AVFoundation 类型添加全局 Sendable 声明 |
| 7. 省略语气词导致回退 | 归一化文本严格匹配，遇到被省略的填充词即整批回退 | 允许忽略明确的语气词参与匹配，但仍将其保存在字幕的原始词序、正文和时间戳中；实词不匹配仍安全回退 |
| 8. 翻译重试与续译 | 无批次重试，重复执行会重新翻译全部行 | 每批失败最多重试一次；取消不重试；跳过已有且未标记需复核的译文；沿用首次批次快照保护在途人工编辑 |

## 验证

- 完整测试集：96 项，0 失败，1 项真实样本测试按既有条件跳过。
- 新增尾部漂移、动画关键帧、multipart 数据完整性、抽取取消、TTS 启动、语气词对齐、翻译重试与跳过已有译文的回归测试。
- 追加抽取成功路径测试，验证 16kHz 单声道 PCM 输出及临时文件清理。
- 使用 Xcode 开发环境执行 `swift test` 和 `swift build -c release`，均成功；两份最终构建日志没有 warning/error。

## 结论范围

代码路径和关键帧非法值已核实；未将报告中的 15–20 倍性能提升、500MB–1GB 峰值内存或特定机器上的导出崩溃当作实测结果。磁盘上传将请求体内存占用限制到分块规模，但需要额外磁盘空间保存 multipart 文件。此修复解决列出的并发捕获告警，不代表整个项目已经迁移至 Swift 6 语言模式。
